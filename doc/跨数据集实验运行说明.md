# Cross-dataset experiments

WheatIns、RWCellIns 与自定义实例分割数据集的准备、预训练、训练和测试。各数据集独立训练与评估；所有命令在仓库根目录执行。

## 1. 环境与权重

CPU 环境；补充安装 OpenAI CLIP（需要 Git）。

```bash
conda env create -f environment-cpu.yml
conda activate blo-inst-cpu
python -m pip install "git+https://github.com/openai/CLIP.git@d05afc436d78f1c48dc0dbf8e5980a9d471f35f6"
```

GPU 运行需使用兼容的 CUDA 版 PyTorch，并将下文 `training.device` 改为 `"0"`；CPU 环境不能仅靠修改设备编号切换到 GPU。

提前准备兼容的 YOLOv7-seg 权重与 [SAM ViT-B 权重](https://dl.fbaipublicfiles.com/segment_anything/sam_vit_b_01ec64.pth)：

```text
weights/
├── yolov7-seg.pt
└── sam_vit_b_01ec64.pth
```

CLIP 使用 `ViT-B/32`，首次加载需下载权重或提前准备缓存；以上大权重不随当前仓库提供。

## 2. 准备自己的数据集

将数据放到本地项目或训练服务器。使用 YOLO 实例分割格式，提前分好互不重叠的 train、val、test。

```text
datasets/CustomIns/
├── images/
│   ├── train/
│   ├── val/
│   └── test/
├── labels/
│   ├── train/
│   ├── val/
│   └── test/
├── train.txt
├── val.txt
└── test.txt
```

图片与标签同名，如 `images/train/001.jpg` 对应 `labels/train/001.txt`；每行一个实例多边形，类别从 0 开始，坐标按图片宽高归一化到 `[0, 1]`。

```text
class_id x1 y1 x2 y2 x3 y3 ...
```

仅有检测框标签不能直接用于当前分割训练。PNG 掩码、COCO polygon/RLE 需先转换成上述格式。

划分清单每行一个图片路径，以 `train.txt` 为例；`./` 相对于清单所在目录：

```text
./images/train/001.jpg
./images/train/002.jpg
```

新建 `data/custom_generalized.yaml`，按实际类别修改 `nc` 与 `names`：

```yaml
path: datasets/CustomIns
train: train.txt
val: val.txt
test: test.txt
nc: 2
names: [class_a, class_b]
```

类别顺序必须与标签 ID 一致；`names` 用于 CLIP 文本提示，建议填写有语义的英文类别名。

```bash
python tools/validate_dataset_layout.py --data data/custom_generalized.yaml
```

### WheatIns / RWCellIns

使用对应项目的 Roboflow v2 COCO 实例分割导出；解压后每个 `train/valid/test` 目录直接包含图片及 `_annotations.coco.json`。

```bash
python tools/convert_wheat_coco.py
python tools/convert_rwcell_coco.py
python tools/validate_dataset_layout.py --data data/wheat_generalized.yaml
python tools/validate_dataset_layout.py --data data/rwcell_generalized.yaml
```

**转换脚本会删除并重建对应的 `datasets/WheatIns` 或 `datasets/RWCellIns`；已准备好的数据跳过转换。** 当前脚本不支持 RLE 或单实例多多边形。旧 `prepare_roboflow_dataset.py` 默认 v1，且仅支持 wheat/rwcell，不能直接导入任意自定义数据集。

## 3. 配置模型

复制 `configs/generalized_blo_wheat.yaml` 为 `configs/srpr_custom.yaml`，保留其余设置，修改以下已有字段；不要重复追加同名 YAML 节点。

```yaml
experiment:
  name: srpr_custom
  description: SRPR-Net on CustomIns

dataset:
  yaml: data/custom_generalized.yaml
  overlap_masks: true
  mask_ratio: 4

model:
  cfg: models/segment/yolov7-seg.yaml
  weights: weights/yolov7-seg.pt

foundation:
  enabled: true
  model_name: ViT-B/32
  fallback_dim: 512

refiner:
  enabled: true
  use_attention: true
  hidden_dim: 256
  num_heads: 8
  num_layers: 2
  dropout: 0.10
  max_center_shift: 0.25
  max_log_scale: 0.35

semantic_prior:
  enabled: false
  learnable_alpha: false

pretraining:
  epochs: 50
  output: runs/pretrain_custom
  patience: 10

training:
  device: "cpu"
  imgsz: 512
  batch_size: 1
  epochs: 20
  workers: 0
  seed: 2026
  inner_split_ratio: 0.50
  amp: false
  cache: null

validation:
  split: val
  batch_size: 1
  interval: 1

output:
  directory: runs/srpr_custom
```

在原 `loss` 和 `inference` 节点中修改以下字段，其余字段保留：

```yaml
loss:
  lambda_constraint: 0.0
  lambda_semantic: 0.0
  lambda_sam_quality: 0.0
  boundary_weight: 0.0

inference:
  max_det: 300
  mask_quality_weight: 0.0
  tta:
    enabled: false
```

**SPRR-Net配置关闭了显式约束与贝叶斯先验模块**，保留 CLIP + Transformer；不要直接使用通用配置中的 `lambda_constraint: 0.08`。边界损失、Mask-IoU 质量融合与 TTA 不用于本流程。

复制来源中的 `lambda_quality: 0.05`、`quality_target: box_iou`、`quality_gain: 0.25` 保留；它们与贝叶斯先验不同。增强、NMS 和固定 `max_det` 按训练／验证集确定，测试前冻结。

## 4. 预训练检测器

确认 `model.weights` 仍指向 `weights/yolov7-seg.pt`：

```bash
python segment/pretrain_detector.py --config configs/srpr_custom.yaml
```

输出 `runs/pretrain_custom/best_detector.pt`，按验证损失选择。

## 5. 训练 SRPR-Net

将 `configs/srpr_custom.yaml` 中已有的 `model.weights` 改为预训练结果，保留 `model.cfg`：

```yaml
model:
  cfg: models/segment/yolov7-seg.yaml
  weights: runs/pretrain_custom/best_detector.pt
```

```bash
python segment/train_generalized.py --config configs/srpr_custom.yaml
```

输出目录 `runs/srpr_custom/`；保存实际配置 `resolved_config.yaml`，按验证集 mask mAP 选择 `best_generalized.pt`。


## 6. 测试与结果

使用保存的实际配置，显式指定独立测试集：

```bash
python segment/val_generalized.py --config runs/srpr_custom/resolved_config.yaml --checkpoint runs/srpr_custom/best_generalized.pt --split test --output runs/srpr_custom/final_test
```

`data/custom_generalized.yaml` 必须包含有效的 `test` 清单；当前评估代码在所选划分缺失时可能回退到 `val`。测试集不参与选模型或调参。

`final_test/metrics.json` 与 `metrics.csv` 中的 `mask_map`、`mask_map50`、`mask_map75` 分别为 mask mAP、AP50、AP75；乘以 100 后报告百分数。

WheatIns/RWCellIns 使用相同流程，分别替换数据 YAML、实验名和输出目录；RWCellIns 建议从 `configs/generalized_blo_rwcell.yaml` 复制配置，保留对应数据增强。每个数据集单独预训练、训练和测试，主流程使用种子 2026。
